# கதாபாத்திர ரெஃபரன்ஸ் ப்ராம்ப்ட்கள் (Tamil) · Character Reference Prompts in Tamil

These are Tamil versions of the prompts in the [series bible](02-series-bible.md). The English and Tamil say the same thing.

## Which language should I paste?
- **For the best images, paste the English version** into Gemini / Nano Banana / Flow. Image and video models are trained mostly on English descriptions, and specific terms (pitambaram, dhrishti dot, kolusu) come out more precisely in English.
- **Use the Tamil version to read, check and edit** the description. If you change something in Tamil, change the English too.
- Gemini does understand Tamil, so the Tamil prompts also work. If a detail comes out wrong (for example, the colour of the dhoti), switch to the English version for that image.
- A mix works well too: write the prompt in English and add one line in Tamil for emotion, e.g. *"முகத்தில் குறும்பும் அன்பும் தெரியணும்"*.

## 1. ஸ்டைல் பிளாக் (STYLE): ஒவ்வொரு ப்ராம்ப்ட்டின் தொடக்கத்திலும்
```
சினிமாத் தரமான ஸ்டைலைஸ்டு 3D அனிமேஷன், உயர்தர இந்திய புராண அனிமேஷன் திரைப்படத் தரம்,
அரை-யதார்த்தமான உடல் விகிதங்கள், பெரிய உணர்ச்சிமிக்க கண்கள், மென்மையான தோல் நிழலமைப்பு,
நுணுக்கமான பாரம்பரிய ஆடைகள் மற்றும் தங்க நகைகள், ஓவியம் போன்ற இதமான பொன்மாலை ஒளி,
ஒளிக்கதிர்கள், மென்மையான பனிமூட்டம், பின்னணி மங்கலான (shallow depth of field) காட்சி,
செறிவான ஆனால் இயற்கையான நிறங்கள் (காவி, மயில் நீலம், மஞ்சள், இலைப் பச்சை, சுடுமண் நிறம்),
பண்டைய இந்திய கிராமம் (கோகுலம், துவாபர யுகம்), செங்குத்தான 9:16 அமைப்பு,
மொபைலில் பார்க்க ஏற்ற பிரேம், லேசான ஃபிலிம் கிரெய்ன்.
```
*(For the long episode, replace "செங்குத்தான 9:16 அமைப்பு, மொபைலில் பார்க்க ஏற்ற பிரேம்" with "கிடைமட்ட 16:9 சினிமா அகலத்திரை அமைப்பு".)*

## 2. தவிர்க்க வேண்டியவை (NEGATIVE): ஒவ்வொரு ப்ராம்ப்ட்டின் முடிவிலும்
```
தவிர்க்கவும்: நிஜ மனிதர்கள் நடித்த புகைப்படம் போன்ற தோற்றம், அனிமே ஸ்டைல், தட்டையான 2D கார்ட்டூன்,
சிதைந்த அல்லது உருகிய முகங்கள், கூடுதல் அல்லது குறைவான விரல்கள், கூடுதல் கை கால்கள், மாறுகண்,
சமமில்லாத கண்கள், மாறும் உடை அல்லது நகைகள், மாறும் தோல் நிறம், நவீனப் பொருட்கள், பிளாஸ்டிக்,
எழுத்துகள், வாட்டர்மார்க், லோகோ, படத்துக்குள் சப்டைட்டில், மங்கலான முகம், அதிகப்படியான நியான் நிறங்கள்,
திகில் தொனி, ஆபாசமான சித்தரிப்பு, மேற்கத்திய இடைக்கால உடைகள்.
```

## 3. ரெஃபரன்ஸ் படம் எடுக்கும் முறை (how to make each character's reference set)

**Step 1, first image:** STYLE + character prompt + this framing line + NEGATIVE.
```
முன்பக்கத்திலிருந்து முழு உடல் படம், நேராக நிற்கிறார், வெற்று வெளிர் சாம்பல் நிறப் பின்னணி,
சீரான மென்மையான ஒளி, முகம் தெளிவாகத் தெரிய வேண்டும்.
```
English: `Full-body front view, standing straight, plain light-grey background, even soft lighting, face clearly visible.`

**Step 2, turnaround sheet** (attach the chosen image from Step 1):
```
இதே கதாபாத்திரம், அதே முகம், அதே உடை. கேரக்டர் டர்ன்அரவுண்ட் ஷீட்: முன்பக்கத் தோற்றம்,
முக்கால் பக்கத் தோற்றம், பக்கவாட்டுத் தோற்றம், பின்பக்கத் தோற்றம், வெற்று வெளிர் பின்னணியில்.
```

**Step 3, expression sheet** (attach the same image):
```
இதே கதாபாத்திரம், அதே முகம். முகபாவ ஷீட், க்ளோஸ்-அப்: வாய்விட்டுச் சிரிப்பு, குறும்புப் புன்னகை,
அப்பாவியான பெரிய கண்கள், சோகம், ஆச்சரியம், கோபம் (லேசாக).
```

**Step 4, close-up portrait** (attach the same image; this is the main face reference for every shot):
```
இதே கதாபாத்திரம், தோள் வரையிலான முன்பக்க க்ளோஸ்-அப் போர்ட்ரெய்ட், வெற்று வெளிர் பின்னணி, சீரான ஒளி.
```

## 4. கதாபாத்திரங்கள்

### 4.1 குழந்தைக் கண்ணன் (வயது ~5)
**மாறக்கூடாத அடையாளங்கள்:** அடர் நீல-கருமை நிறத் தோல் · மை தீட்டிய பெரிய கண்கள் · வலது கன்னத்தில் திருஷ்டிப் பொட்டு · குடுமியில் மயில் இறகு · மஞ்சள் பட்டு வேட்டி · குறும்புப் புன்னகை
```
கதாபாத்திரம்: குழந்தைக் கண்ணன், 5 வயது இந்தியச் சிறுவன். மழை மேகம் போன்ற அடர் நீல-கருமை நிறத் தோல்,
மென்மையான பளபளப்புடன். உருண்டையான கன்னங்கள், மை தீட்டிய பெரிய பாதாம் வடிவ அடர் பழுப்புக் கண்கள்,
வலது கன்னத்தில் சிறிய கருப்பு திருஷ்டிப் பொட்டு, நெற்றியில் வெள்ளையும் தங்கமும் கலந்த U வடிவ நாமம், நீண்ட இமைகள், சிறிய மூக்கு,
சிறிய பற்கள் தெரியும் குறும்பான பாதிப் புன்னகை. கருப்பு சுருள் முடி தலையின் மேல் சிறிய குடுமியாகக் கட்டப்பட்டு,
அதில் ஒரு மயில் இறகு செருகப்பட்டுள்ளது; நெற்றியில் சில சுருள் முடிகள் விழுகின்றன.
குடுமியைச் சுற்றி மெல்லிய எளிய தங்க கிரீடப் பட்டை. இடுப்பில் தங்கக் கச்சையுடன் கட்டிய
பளீர் மஞ்சள் பட்டு வேட்டி (பீதாம்பரம்). சிறு மணிகள் கொண்ட மெல்லிய தங்க அரைஞாண்,
தங்கத் தோள்வளைகள், சிறிய தங்கக் காதணிகள். துளசி மணி மாலை, சிறிய வெள்ளை மல்லிகை மற்றும்
ஆரஞ்சு செண்டுமல்லிப் பூக்களால் ஆன குட்டை மாலை. சிறு மணிகள் கொண்ட தங்கக் கொலுசுகள், வெறுங்கால்.
இடுப்புக் கச்சையில் செருகிய சிறிய மூங்கில் புல்லாங்குழல்.
```

### 4.2 இளைஞன் கண்ணன் (வயது ~16, அத்தியாயம் 15 முதல்)
```
கதாபாத்திரம்: இளைஞன் கண்ணன், 16 வயது. குழந்தைப் பருவத்தில் இருந்த அதே அடர் நீல-கருமை நிறத் தோல்,
அதே மை தீட்டிய பாதாம் வடிவக் கண்கள். மெலிந்த, கட்டுடலான உடல்; மென்மையான, தன்னம்பிக்கையான புன்னகை.
தோள் வரை நீளும் கருப்பு சுருள் முடி, ஒரு பகுதி மேலே கட்டப்பட்டுள்ளது. பெரிய மயில் இறகுடன் தங்க கிரீடம்.
மஞ்சள் பட்டு வேட்டி, ஒரு தோளில் அடர் நீல அங்கவஸ்திரம். காட்டுப் பூக்களால் ஆன நீண்ட வைஜயந்தி மாலை.
மகர மீன் வடிவத் தங்கக் காதணிகள் (மகர குண்டலங்கள்). வலது கையில் மூங்கில் புல்லாங்குழல்.
```

### 4.3 யசோதை (வயது ~28)
```
கதாபாத்திரம்: யசோதை, 28 வயது இந்திய கிராமத்துத் தாய். இதமான கோதுமை-பழுப்பு நிறத் தோல், அன்பான நீள்வட்ட முகம்,
பெரிய உணர்ச்சிமிக்க கண்கள், நெற்றியில் சிவப்புக் குங்குமப் பொட்டு. மல்லிகைப் பூ சூடிய நீண்ட அடர்த்தியான கருப்புப் பின்னல்.
கடுகு-மஞ்சள் நிற பார்டர் கொண்ட அடர் சிவப்பு பருத்திப் புடவை, பழங்கால எளிய முறையில் கட்டியது; அரைக்கை ரவிக்கை.
இரு கைகளிலும் கண்ணாடி மற்றும் தங்க வளையல்கள், எளிய தங்கச் சங்கிலி, சிறிய மூக்குத்தி, வெள்ளிக் கொலுசுகள்.
எளிதில் சிரிப்பாக மாறும் இதமான தாய்மை முகபாவம்.
```

### 4.4 பலராமன் (வயது ~7, கண்ணனின் அண்ணன்)
```
கதாபாத்திரம்: பலராமன், 7 வயது இந்தியச் சிறுவன். வெளிர் சிவந்த நிறத் தோல், உறுதியான உடல், தன்னம்பிக்கையான முகம்,
குடுமியாகக் கட்டிய குட்டையான அலை முடி. அடர் இண்டிகோ-நீல பருத்தி வேட்டி, எளிய தங்கக் காதணிகள் மற்றும் தோள்வளைகள்,
சிறிய வெள்ளைச் சங்கு மணி மாலை.
```

### 4.5 ஸ்ரீதாமா (வயது ~6, வலிமையான நண்பன்)
```
கதாபாத்திரம்: ஸ்ரீதாமா, 6 வயது இந்திய இடையர் சிறுவன். நடுத்தரப் பழுப்பு நிறத் தோல், குண்டான உறுதியான உடல்,
உருண்டை முகம், வாய்விட்ட பெரிய சிரிப்பு. பச்சைத் துணித் தலைப்பட்டையுடன் குட்டையான கலைந்த முடி.
குட்டையான வெளிர் வெள்ளை (off-white) பருத்தி வேட்டி. கழுத்தில் கயிற்றில் கட்டிய சிறிய மரத்தாலான மாட்டு மணி.
```

### 4.6 சுபலன் (வயது ~5, பயந்த சுபாவ நண்பன்)
```
கதாபாத்திரம்: சுபலன், 5 வயது இந்திய இடையர் சிறுவன். வெளிர் பழுப்பு நிறத் தோல், மெலிந்த சிறிய உடல்,
பயந்த பெரிய கண்கள், அடிக்கடி உயர்ந்திருக்கும் புருவங்கள். சிறிய குடுமியாகக் கட்டிய முடி.
குட்டையான காவி-ஆரஞ்சு பருத்தி வேட்டி, மணிக்கட்டில் சிவப்பு மணிக் கயிறு, கையில் சிறிய மேய்ச்சல் குச்சி.
```

### 4.7 கோமதி அக்கா (பக்கத்து வீட்டுப் பெண், நீண்ட அத்தியாயம் 1)
```
கதாபாத்திரம்: கோமதி அக்கா, 30 வயது கோகுலத்துக் கிராமப் பெண். மாநிறத் தோல், கூர்மையான ஆனால் அன்பான முகம்,
பெரிய உணர்ச்சிமிக்க கண்கள், சில மல்லிகைப் பூக்களுடன் கொண்டை. மெரூன் பார்டர் கொண்ட கிளிப்பச்சை பருத்திப் புடவை,
பித்தளை வளையல்கள், மூக்குத்தி. சீக்கிரம் கோபப்படுவாள், அதைவிடச் சீக்கிரம் சிரிப்பாள்.
```

### 4.8 பாட்டி (கோபி 2)
